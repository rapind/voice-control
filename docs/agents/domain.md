# Domain Docs

This is a single-context repository.

Before exploring code, read root `CONTEXT.md` and ADRs under `docs/adr/` that touch the area being changed. If those files do not exist, proceed without flagging their absence. They are created only when the project has domain language or architectural decisions worth recording.

Use terminology from `CONTEXT.md` in issue titles, tests, plans, and implementation. If a proposed change conflicts with an ADR, state the conflict instead of silently overriding the recorded decision.
